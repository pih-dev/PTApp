# SpotSet v2.30.1 — tap the mark, replay the show

**Date:** 2026-08-22 · **Asked for by Pierre**, right after approving the opening ("amazing").

The header now has two targets: the **word** SpotSet opens the movement library (as before), and
the **mark** replays the opening — animation and sound — looping until you stop it, with Replay
and Close buttons (tapping anywhere else also closes).

And because tapping the mark is a user gesture, **the sound now plays on the web version too** —
the browser's autoplay rule only blocks sound nobody asked for. The launch opening stays silent on
web and sounding in the native app, exactly as before.
